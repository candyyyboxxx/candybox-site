candybox プライバシーポリシー

制定日: 2026年12月1日

最終改定日: 2026年12月1日

candybox は、個人の開発者がつくって運営しているアプリです。 わたしたち（開発者）は、あなたの情報をできるだけ集めないことを方針にしています。 このページは、何を集めて、何に使い、いつ消すのかを説明します。

はじめに：3つの約束

  1. アドレス帳（連絡先）は読み取りません。 位置情報も取得しません。
  2. 知らない人は入れません。 candybox は検索で見つかりません。友だちの招待は、あなた自身がリンクを渡すときだけ成立します。
  3. ムービーは13か月で消します。 翌年の同じ月にもう一度開けるようにするためです。その後は削除します。

第3条（集めない情報）

わたしたちは、次のものを集めません。

  1. アドレス帳・連絡先
  2. 位置情報
  3. 写真ライブラリ全体（投稿のために選んだ・撮影したムービー以外）
  4. 広告識別子（IDFA）。広告のトラッキングは行いません。

4-2. メールアドレス。 Sign in with Apple でメールアドレスの提供を要求していないため、Appleの非公開リレーアドレスも含めて一切受け取りません。

  1. 電話番号
  2. 本名、住所、生年月日

第4条（使う目的）

集めた情報は、次の目的のためだけに使います。

  1. アカウントの作成と本人確認
  2. グループの作成、招待、メンバーの管理
  3. ムービーを預かり、月が変わったときに届けること
  4. プッシュ通知を送ること
  5. 通報の対応、ルール違反への対応、不正利用の防止
  6. 障害の調査と、アプリの品質改善
  7. あなたからの問い合わせへの回答
  8. 法令にもとづく対応

これ以外の目的には使いません。目的を増やすときは、事前にお知らせします。

第5条（ムービーが見えないしくみ）

  1. 投稿されたムービーは、その月の終わりまであなたを含めグループの誰にも見えません。投稿した本人にも、受け取る本人にも見えません。
  2. 月が変わる瞬間に、グループ全員の瓶が同時に開きます。
  3. わたしたちは、ムービーを宣伝・広告・AIの学習に使いません。
  4. わたしたちは、法令対応・通報対応・不正調査のために必要な場合にかぎり、ムービーを確認することがあります。
  5. 本アプリは端末間の終端暗号化（エンドツーエンド暗号化）を採用していません。ムービーは Google のサーバー上で保存時に暗号化されますが、運営者は技術的には内容を確認できます。前項の目的以外では確認しません。

第7条（第三者への提供）

  1. わたしたちは、あなたの個人情報を第三者に売ったり、渡したりしません。
  2. ただし、次の場合は例外です。

- あなたの同意があるとき - 法令にもとづくとき（裁判所や警察からの適法な要請を含む） - 人の生命・身体・財産を守るために緊急に必要なとき

  1. グループのメンバーには、あなたのニックネームと、あなたが投稿したムービー（開いた後）が見えます。これは本アプリのしくみによるもので、第三者提供ではありません。

第8条（外部の事業者への委託）

  1. わたしたちは、サーバーの運用を Google の Firebase に委託しています。

- Cloud Storage for Firebase（ムービーの保存） - Cloud Firestore（アカウント・グループ・通報の情報） - Cloud Functions（処理の実行） - Firebase Cloud Messaging（プッシュ通知）

  1. 委託先には、契約にもとづいて適切な管理を求めています。
  2. Firebase 以外の外部サービス（アクセス解析、クラッシュレポート、広告など）は利用していません。

第9条（外国にあるサーバーでの取り扱い）

  1. 上記の情報は、Google のサーバーで取り扱われます。処理の実行は日本（asia-northeast1）で行っています。保存先の国・地域は Firebase プロジェクトの設定に従います。
  2. 日本国外のサーバーで取り扱われる場合、その国の個人情報保護の制度は日本と異なることがあります。
  3. わたしたちは、個人情報保護法第28条にしたがい、委託先であるGoogleが同法の基準に適合する体制を継続的に講じていることを確認する方法で対応します。
  4. 詳しい情報が必要な方は、問い合わせ窓口までご連絡ください。

第10条（外部送信について）

電気通信事業法第27条の12にもとづき、本アプリが利用者の端末から外部に送信する情報をお知らせします。

本アプリには、アクセス解析SDKも広告SDKも組み込んでいません。

第11条（安全管理のためにしていること）

  1. 通信はすべて暗号化しています（TLS）。
  2. サーバー上の情報は、Google のサーバー側機能により保存時に暗号化されています。
  3. データベースのアクセス制御（Firebase セキュリティルール）で、本人と宛先以外が読めないようにしています。
  4. 管理用のアカウントには多要素認証を設定しています。
  5. 開発者本人以外は、情報にアクセスできません。
  6. 月末まではムービーを開けないしくみを、サーバー側で制御しています。

第12条（あなたができること）

  1. アカウントの削除: アプリの中からいつでも削除できます。削除すると、アカウント情報とあなたが投稿したムービーは削除されます。
  2. 開示・訂正・削除・利用停止の請求: 個人情報保護法にもとづき、わたしたちが持っているあなたの情報について、開示、訂正、追加、削除、利用の停止、第三者提供の停止を請求できます。
  3. 請求の方法: candyyyboxxx@gmail.com にメールしてください。本人であることを確認したうえで、2週間以内に回答します。
  4. 手数料はかかりません。
  5. 通知の停止: プッシュ通知は、端末の設定からいつでも止められます。

第13条（未成年の方の情報）

  1. 本アプリは10代から20代の方の利用を想定しています。
  2. 18歳未満の方は、親など法定代理人の同意を得てから使ってください。
  3. わたしたちは、未成年の方の情報をとくに慎重に扱います。広告やプロファイリングには使いません。
  4. 法定代理人の方からの削除のご依頼にも対応します。問い合わせ窓口までご連絡ください。
  5. 本アプリは13歳以上の方を対象としています。13歳未満の方は利用できません。
  6. 13歳未満の方がアカウントをつくっていることが分かった場合、そのアカウントと投稿を削除します。

第14条（Cookie・広告）

本アプリは広告を表示しません。行動ターゲティング広告のためのトラッキングも行いません。

第15条（情報漏えいが起きたとき）

万一、個人情報の漏えいが起きた場合は、法令にしたがって個人情報保護委員会に報告し、対象となる方にお知らせします。
