candybox 利用規約

制定日: 2026年12月1日 最終改定日: 2026年12月1日

candybox（キャンディボックス）は、個人の開発者がつくって運営しているアプリです。 この規約は、わたしたち（開発者）とあなた（利用者）の約束ごとです。 読みやすさを優先して短く書いています。わからないところは問い合わせてください。

第1条（この規約について）

  1. この規約は、candybox（以下「本アプリ」）の利用条件を定めるものです。
  2. 本アプリを使いはじめた時点で、この規約に同意したものとします。
  3. 本アプリは法人ではなく、個人の開発者（以下「わたしたち」）が運営しています。

第2条（ことばの意味）

  1. 「グループ」とは、招待でつながった2人から12人（標準は5人）の集まりです。
  2. 「瓶（びん）」とは、利用者ごとに用意される、ムービーを受け取る場所です。
  3. 「ムービー」とは、利用者が投稿する2秒の動画です。
  4. 「投稿」とは、グループの中の特定の1人の瓶にムービーを入れることです。

第3条（未成年の方の利用）

  1. 18歳未満の方は、親など法定代理人の同意を得てから使ってください。
  2. 本アプリを使いはじめた時点で、その同意を得ているものとして取り扱います。
  3. 年齢によって使える機能が変わることがあります。
  4. 本アプリは13歳以上の方を対象としています。13歳未満の方は利用できません。

第4条（アカウント）

  1. アカウントは Sign in with Apple でつくります。わたしたちは、Apple からあなたの氏名もメールアドレスも受け取りません。
  2. アカウントは1人につき1つです。他人に貸したり、売ったりできません。
  3. Apple ID の管理はあなたの責任でお願いします。
  4. アカウントはいつでもアプリの中から削除できます（第13条）。

第5条（グループと招待）

  1. グループは招待制です。検索して見つけることはできません。
  2. 招待は、あなた自身が招待リンクを相手に渡すことで行います。
  3. わたしたちは、あなたのアドレス帳（連絡先）を読み取りません。 知らない人を自動でおすすめすることもしません。
  4. グループの人数は2人から12人です（標準は5人）。
  5. 招待リンクを誰に渡すかはあなたが決めます。知らない人に渡さないでください。

第6条（ムービーの投稿）

  1. ムービーは2秒です。投稿先は、グループの中の特定の1人です。
  2. 投稿したムービーは、第7条のしくみで開くまで、取り消し以外の方法で内容を確認できません。
  3. 投稿するムービーについて、あなたは次のことを守ってください。

- 映っている人の許可をとること - 第三者の権利（著作権・肖像権など）を侵害しないこと

第7条（開くタイミング）

  1. 投稿されたムービーは、その月の終わりまで、あなたを含めグループの誰にも見えません。投稿した本人にも、受け取る本人にも見えません。
  2. 月が変わる瞬間に、グループ全員の瓶が同時に開きます。
  3. このしくみは本アプリの中心です。先に見る方法は用意しません。
  4. 通信障害などで開封が遅れることがあります。

第8条（保存期間）

  1. ムービーは、投稿から13か月保存します。
  2. 13か月にしているのは、翌年の同じ月にもう一度開けるようにするためです。
  3. 13か月を過ぎたムービーは削除します。削除後は復元できません。
  4. 大事なムービーは、開いている間にあなたの端末に保存してください。

第9条（やってはいけないこと）

次のことを禁止します。

  1. 法令や公序良俗に反する行為
  2. 他人への誹謗中傷、いじめ、脅迫、ハラスメント
  3. わいせつな内容、児童の性的な内容の投稿（法令違反であり、通報対象です）
  4. 他人の権利（著作権・肖像権・プライバシーなど）を侵害する投稿
  5. 他人になりすますこと
  6. 本人の許可なく、他人が映ったムービーを外部に公開すること
  7. 招待リンクを公開の場（SNSや掲示板など）にばらまくこと
  8. 出会い目的の利用、金銭や物品の勧誘、宗教・政治への勧誘
  9. 本アプリの改変、解析、不正アクセス、自動化ツールによる操作
  10. サーバーに過大な負荷をかける行為
  11. その他、わたしたちが不適切と判断する行為

第10条（ムービーの権利）

  1. あなたが投稿したムービーの権利は、あなたのものです。わたしたちのものにはなりません。
  2. わたしたちは、本アプリを動かすために必要な範囲でだけ、ムービーを保存・送信・表示します。
  3. わたしたちは、ムービーを宣伝や広告に使いません。
  4. わたしたちは、ムービーをAIの学習に使いません。
  5. わたしたちは、法令対応・通報対応・不正調査のために必要な場合にかぎり、ムービーを確認することがあります。
  6. 本アプリは端末間の終端暗号化（エンドツーエンド暗号化）を採用していません。ムービーは保存時に暗号化されますが、運営者は技術的には内容を確認できます。前項の目的以外では確認しません。

第11条（通報・除外・ブロック）

  1. 困ったことがあったら、アプリの中から通報できます。
  2. グループをつくった人は、グループから他のメンバーを除外できます。
  3. 個人間のブロック機能があります。ブロックした相手は、あなたの瓶に投稿できなくなり、その相手が過去に投稿したムービーもあなたの画面には表示されなくなります。
  4. 通報を受けたら、わたしたちはできるだけ早く内容を確認し、必要な対応をとります。
  5. 連絡先: candyyyboxxx@gmail.com

第12条（利用の制限・停止）

  1. この規約に違反した場合、わたしたちは予告なく、投稿の削除、機能の制限、アカウントの停止・削除を行うことがあります。
  2. 緊急の場合は、先に対応してから連絡することがあります。
  3. 判断の理由をすべてお伝えできない場合があります。

第13条（アカウントの削除）

  1. アカウントは、アプリの中からいつでも削除できます。
  2. 削除すると、あなたのアカウント情報と、あなたが投稿したムービーは削除されます。
  3. わたしたちは定期バックアップを取得していません。削除の反映には、サーバー側の処理上、短時間の遅れが生じることがあります。
  4. 法令で保存が必要な情報は、必要な期間だけ残すことがあります。

第14条（サービスの変更・停止・終了）

  1. わたしたちは、本アプリの内容を変更したり、機能を追加・削除したりすることがあります。
  2. メンテナンスや障害、天災などのときは、予告なく一時停止することがあります。
  3. 本アプリを終了することがあります。終了するときは、終了日の30日前までにアプリ内でお知らせします。
  4. 終了にともなうムービーの削除について、わたしたちは責任を負いません。

第15条（料金）

  1. 現時点では無料です。
  2. 将来、有料の機能を追加することがあります。そのときは事前にお知らせします。

第16条（免責）

  2. ムービーが消えた、開かなかった、届かなかったことによる損害について、わたしたちは責任を負いません。
  3. 利用者同士のトラブルは、当事者の間で解決してください。
  4. ただし、わたしたちに故意または重大な過失がある場合は、この条文の免責は適用されません。
  5. わたしたちが損害賠償の責任を負う場合、その範囲は通常生じる損害に限られ、賠償額の上限は金1万円とします。
